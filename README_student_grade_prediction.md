# 🎓 Student Grade Prediction Dashboard

An interactive machine-learning web app that estimates a student's final grade from selected student-performance and lifestyle-related inputs.

## 🚀 Live Demo

**Try the deployed application:** https://student-grade-prediction-harsh.streamlit.app/

## ✨ Features

- Predicts an estimated final grade using a trained regression model.
- Accepts 13 student-related inputs, including age, parents' education, study time, past class failures, absences, and other lifestyle or wellbeing factors.
- Displays the predicted grade on a 0–20 scale.
- Shows a summary of the values entered.
- Built with Streamlit for a simple, interactive web interface.

## 🧠 Model Inputs

The dashboard uses these 13 features:

`age`, `Medu`, `Fedu`, `traveltime`, `studytime`, `failures`, `famrel`, `freetime`, `goout`, `Dalc`, `Walc`, `health`, and `absences`.

The prediction is generated by the saved model file, `improved_regression_model.pkl`.

## 📁 Project Files

- `student_grade_dashboard.py` — Streamlit application and prediction interface.
- `improved_regression_model.pkl` — trained regression model used to generate predictions.
- `requirements.txt` — Python packages required to run the application.

## ⚙️ Run Locally

### 1. Install Python
Use Python 3.10 or later.

### 2. Install dependencies
Open a terminal in the project folder and run:

```bash
pip install -r requirements.txt
```

### 3. Keep the required files together
Make sure `student_grade_dashboard.py`, `improved_regression_model.pkl`, and `requirements.txt` are in the project folder.

### 4. Start the dashboard

```bash
streamlit run student_grade_dashboard.py
```

Streamlit will provide a local URL that you can open in your browser.

## ⚠️ Limitations

- The predicted grade is an estimate, not a guaranteed result.
- Prediction quality depends on the training data and the performance of the trained model.
- Regression models can sometimes return values outside the usual 0–20 grade range.
- This project is intended for educational and demonstration purposes. Predictions should not be used as the sole basis for decisions about a student.
