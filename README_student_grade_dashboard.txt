# Student Grade Prediction Dashboard

## Project
Option C: Prediction Dashboard

## Files required
- student_grade_dashboard.py
- improved_regression_model.pkl
- requirements_dashboard.txt

## Installation
Install Python 3.10 or later, then run:
pip install -r requirements_dashboard.txt

## Run
Keep the app and model in the same folder, then run:
streamlit run student_grade_dashboard.py

## Inputs
The dashboard uses 13 features from the student-performance dataset.

## Limitations
Predictions are estimates and depend on the training data.
Regression outputs may fall outside the usual 0–20 grade range.
The dashboard is an educational project, not a substitute for professional judgment.
